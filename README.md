# Rewrite Reborn

จัดระเบียบลายมือภาษาไทย ภาษาอังกฤษ และตัวเลขอารบิก ด้วยพีชคณิตเชิงเส้น โดยรักษาเอกลักษณ์ลายมือเดิม

ระบบไม่ได้แปลงลายมือเป็นตัวพิมพ์แบบ OCR แต่ "ยกหมึกจริง" ของแต่ละตัวอักษรไปวางใหม่ด้วยเมทริกซ์แปลง
(เลื่อน เอียง ย่อ/ขยาย และปรับรูปเล็กน้อย) ให้ตัวอักษรอยู่บนเส้นบรรทัด เอียงเท่ากัน ขนาดสม่ำเสมอ
ช่องไฟชัดเจน และหน้ากระดาษเป็นระเบียบ


## ติดตั้ง

ต้องใช้ Python 3.9 ขึ้นไป (ทดสอบแล้วกับ 3.9 และ 3.13)

```bash
cd rewrite_reborn
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

ถ้าต้องการวัด OCR confidence ให้ติดตั้ง [tesseract](https://github.com/tesseract-ocr/tesseract) พร้อมภาษา `tha` และ `eng` เพิ่ม (ไม่บังคับ)

## ใช้งาน

### เว็บแอปสำหรับผู้ใช้ (แนะนำ)

```bash
python user_web/server.py                        # เปิด http://localhost:8000 ให้อัตโนมัติ
python user_web/server.py --port 8080 --no-browser
```

กด Ctrl+C ในหน้าต่าง terminal เพื่อหยุด ถ้าแก้ไฟล์หน้าเว็บแล้วไม่เห็นผล ให้รีเฟรชแบบล้าง cache (Ctrl+Shift+R / Cmd+Shift+R)

1. ลากไฟล์มาวาง (อัปได้หลายไฟล์ หลายหน้า)
2. แตะภาพย่อเพื่อเลือก/ยกเลิกหน้า (Shift + คลิก = เลือกหลายหน้าติดกัน, ปุ่ม ⤢ = ดูหน้าใหญ่)
3. ตั้งค่าแบบเข้าใจง่าย: ความแรง (เบา ๆ / พอดี / เต็มที่), สิ่งที่จะจัด, ความเอียง, พื้นหลังผลลัพธ์ และตั้งค่าเพิ่มเติม
4. ดูผลเทียบซ้าย-ขวา แตะภาพเพื่อดูเต็มจอ (ซูม/เลื่อนสองฝั่งพร้อมกัน) แล้วดาวน์โหลด PNG / PDF / ZIP

### หน้าจอทดสอบสำหรับผู้พัฒนา (Streamlit)

```bash
streamlit run app.py
```

1. อัปโหลดไฟล์ 1–3 ไฟล์ (PDF / PNG / JPG)
2. ใส่หน้าของ PDF ที่ต้องการ เช่น `1`, `1,3`, `2-4`
3. ปรับพารามิเตอร์ทางซ้ายถ้าต้องการ (ค่าเริ่มต้นใช้ได้กับโน้ตส่วนใหญ่) แล้วกด **รัน pipeline**
4. ดูผลได้ 4 แท็บ และดาวน์โหลดผลเป็น PDF / ZIP / PNG

| แท็บ | ใช้ทำอะไร |
|---|---|
| เทียบก่อน/หลัง | 3 มุมมอง: เลื่อนเทียบ (มีซูม), ซ้าย-ขวา, ซ้อนทับ (แดง = เดิม, น้ำเงิน = ใหม่) พร้อมตัวชี้วัดสรุป |
| Debug | baseline, x-height, กรอบหลักของตัวอักษร (oriented bounding box), กลุ่มตัวอักษร, เส้นโยงสระ/วรรณยุกต์ไปตัวเจ้าของ, สิ่งที่ไม่ใช่ตัวอักษร |
| ขั้นตอนเตรียมภาพ | ภาพผลของแต่ละขั้นในส่วน A |
| ตัวชี้วัดละเอียด | ตารางก่อน/หลัง, จำนวนองค์ประกอบ, เวลาที่ใช้แต่ละขั้น |

ผลจะถูก cache ไว้ กดรันซ้ำด้วยพารามิเตอร์เดิมจะไม่คำนวณใหม่ (ถ้าแก้โค้ด cache จะล้างเอง)

### Command line

```bash
python run.py notes.pdf
python run.py a.pdf b.png c.pdf --pages 1-2
python run.py notes.pdf --alpha 0.6 --no-spacing
python run.py notes.pdf --set shape_strength=0.8 --set regularize_indent=false
```

ผลของแต่ละหน้าอยู่ใน `outputs/<ชื่อไฟล์>_p<หน้า>/`

| ไฟล์ | เนื้อหา |
|---|---|
| `input.png` | ภาพเข้า |
| `output.png` | ผลลัพธ์ |
| `compare.png` | ภาพเทียบซ้าย-ขวา |
| `debug.png` | ภาพตรวจสอบ |
| `metrics.json` | ตัวชี้วัด + พารามิเตอร์ที่ใช้ |

- ภาพ PNG / JPG (ภาพหน้าจอ, ภาพถ่าย, สแกน)

## ความสามารถ

**การเตรียมภาพ**
- รองรับพื้นหลังสีขาว สีเข้ม (โหมดมืด) และกระดาษเส้น จุด หรือกริด
- ปรับแสงที่ไม่สม่ำเสมอ แล้วแปลงเป็นขาว-ดำด้วย adaptive threshold
- แก้หน้าเอียงโดยอ้างอิงกระดาษก่อน (เส้นบรรทัด → ลายจุด → แถวตัวหนังสือ) เลือกได้ว่าจะหมุนทั้งหน้าให้ตรง หรือคงกรอบภาพเดิม

**การจัดลายมือ**
- ตัวอักษรอยู่บนเส้นบรรทัดเดียวกัน (baseline จาก least squares)
- มุมเอียงสม่ำเสมอ (คงความเอียงประจำตัวผู้เขียนไว้ หรือเลือกตั้งตรง)
- ขนาดสม่ำเสมอภายในกลุ่มเดียวกัน (ตัวกลาง / ตัวมีหางขึ้น / ตัวมีหางลง)
- ช่องไฟ: ช่องระหว่างคำขยายได้อย่างเดียว ช่องในคำบีบได้อย่างเดียว ช่องที่ก้ำกึ่งไม่แตะ ทำให้คำไม่ติดกันและไม่แตกเป็นชิ้น
- สระ วรรณยุกต์ และเครื่องหมายเคลื่อนตามตัวหลักเสมอ
- ตัวเดียวกันหน้าตาใกล้กันขึ้น โดยใช้ต้นแบบที่หาจากลายมือของผู้เขียนเอง
- ระยะห่างระหว่างบรรทัดเท่ากัน (ไม่ทำบนกระดาษที่มีเส้นบรรทัด) และหัวบรรทัดในย่อหน้าระดับเดียวกันเริ่มตรงกัน

**สิ่งที่ระบบไม่แตะ (คงไว้ตามเดิม)**
- ภาพที่แปะมา ตาราง และภาพหน้าจอ
- หัวเรื่องตัวใหญ่หรือข้อความที่พิมพ์
- บรรทัดที่เรียบร้อยอยู่แล้ว
- ข้อความในกรอบหรือเมฆ ภาพวาด ลูกศร และวงเล็บใหญ่
- สูตรคณิตศาสตร์ (เศษส่วนอย่าง dy/dx ถูกผูกเป็นหน่วยเดียว เลื่อนตามบรรทัดได้แต่ไม่ถูกบิด)
- กระดาษ ลายกริด และไฮไลต์เดิม (ผลลัพธ์วางบนกระดาษเดิม)

**การวาดผล**
- `warp` (ค่าเริ่มต้น): ยกพิกเซลหมึกจริงไปวางใหม่ ความหนาและความนุ่มของเส้นตามต้นฉบับ
- `contour`: วาดจาก contour ที่ผ่าน moving average เส้นเรียบขึ้น แต่อาจหนาขึ้นเล็กน้อย

## ขั้นตอนการทำงาน ↔ โค้ด

```
rr/
  config.py       พารามิเตอร์ทั้งหมด (ค่าขนาดเป็นสัดส่วนของความสูงตัวอักษร h)
  io_loader.py    A1  นำเข้า PDF/ภาพ แยกประเภท (pdf_vector / pdf_digital / pdf_scan / img_digital / img_photo)
  preprocess.py   A2  ตรวจพื้นมืด/สว่าง, ปรับแสง (หารด้วยพื้นหลังจาก morphological closing)
                  A3  Gaussian blur (2D convolution) → Adaptive Threshold
                  A4  หาเส้นบรรทัดกระดาษ (Hough + least squares) → ลบ → แก้หน้าเอียง
  components.py   B1  contour + hierarchy (ขอบนอก + รู) = 1 ตัวอักษร (glyph)
                  B2  ความสูงอ้างอิง h, ความหนาเส้น
                  B3  แยก text / non-text / noise
  nontext.py      B3  กฎแยกภาพ กรอบ วงเล็บ เส้น ภาพวาด หัวเรื่อง
                  B11 คงข้อความในกรอบ/สูตรไว้, ผูกเศษส่วนและตัวยก/ตัวห้อย
  layout.py       B4  จัดบรรทัด (line tracking) + รวมบรรทัดที่ต่อกัน
                  B5  baseline ด้วย normal equation (AᵀA)⁻¹Aᵀy + ตัด outlier, x-height
                  B6  แบ่งโซนบน/กลาง/ล่าง ด้วย vector projection
                  B7  ผูกสระ/วรรณยุกต์กับตัวฐาน
                  B8  กลุ่ม mid / asc / desc / tall
                  B10 แยกช่องในคำ/ช่องระหว่างคำ (1D k-means)
  correction.py   C1  มุมเอียงจากเวกเตอร์ทิศทางของช่วงเส้นที่เกือบตั้ง (shrinkage เข้าหาค่าของคำ)
                  C3  ขนาดเป้าหมาย = มัธยฐานของกลุ่ม
                  C4  ช่องไฟ (กฎทางเดียว)
                  C5  บรรทัดสั้น/บรรทัดที่ freeze → ไม่แก้
                  T = Tr(dx) · [I + α(Tr(dy)·about(K·S) − I)]
  refine.py       C3.5 รูปทรงสม่ำเสมอ: จับกลุ่มด้วย cosine similarity → ต้นแบบเฉลี่ย
                       → affine จาก least squares (ตรวจด้วย SVD) + บิดเฉพาะจุด (moving average)
                  C6  ระยะบรรทัดเท่ากัน (least squares y = c₀ + c₁k) + แนวหน้าบรรทัด
  geometry.py     เครื่องมือพีชคณิตเชิงเส้น: covariance, eigen, OBB, LSQ, affine 3×3,
                  circulant moving average, cosine similarity, RBF displacement
  render.py       D   แปลงหมึกจริงด้วย affine (+ remap สำหรับการบิดเฉพาะจุด) หรือวาดจาก contour
                      → ประกอบกลับบนกระดาษเดิม
  evaluate.py     E   ตัวชี้วัดก่อน/หลัง + OCR (ไม่บังคับ)
  pipeline.py     รวมทุกขั้นสำหรับหน้าเดียว
user_web/         เว็บแอปสำหรับผู้ใช้ (FastAPI + HTML/CSS/JS)
app.py            หน้าจอทดสอบสำหรับผู้พัฒนา (Streamlit)
run.py            CLI
report_tools/     สถิติชุดข้อมูล (dataset_stats.py), ภาพประกอบรายงาน (make_figures.py), เทียบกับ OCR (identity_vs_ocr.py)
```

## หลักการพีชคณิตเชิงเส้นที่ใช้

| หลักการ | ใช้ทำอะไร | ที่อยู่ในโค้ด |
|---|---|---|
| เวกเตอร์แทนจุดขอบ | contour ของแต่ละตัวเป็นชุดจุด (x, y) เรียงต่อเนื่อง | `components.py` |
| บวก/ลบเวกเตอร์, norm | เวกเตอร์ทิศทางระหว่างจุดติดกัน, ความยาวช่วงเส้น | `geometry.direction_vectors`, `norms` |
| Dot product / มุม | แยกส่วนตรงกับส่วนโค้ง (คงมุมแหลมตอน smooth), เลือกช่วงเส้นที่เกือบตั้ง | `geometry.turning_angles`, `slant_segments` |
| Cosine similarity | ความคงเอกลักษณ์ก่อน/หลัง, จับกลุ่มตัวที่หน้าตาเหมือนกัน | `geometry.shape_cosine`, `refine.cluster_glyphs` |
| Vector projection | ระยะตั้งฉากจากจุดถึง baseline, แบ่งโซนบน/กลาง/ล่าง | `layout.Line.sdist` |
| Covariance + eigenvector | ทิศทางหลัก/แกนตั้งฉาก → oriented bounding box, แยกเส้นกับตัวอักษร, ตรวจเส้นเศษส่วน | `geometry.principal_axes`, `oriented_bbox`, `nontext.py` |
| Normal equation (AᵀA)⁻¹Aᵀy | baseline, เส้นบรรทัดกระดาษ, ระยะบรรทัด, affine เข้าหาต้นแบบ | `geometry.fit_line_lsq`, `refine.fit_affine` |
| SVD | ตรวจว่า affine ไม่ยืด/บีบ/หมุน/พลิกเกินกำหนด | `refine.affine_ok` |
| Shear / Scaling (diagonal) / Translation | แก้เอียง, ปรับขนาด, ยกลงเส้นบรรทัด, จัดช่องไฟ/บรรทัด | `geometry.shear_matrix`, `scale_matrix`, `T_translate` |
| Composition + affine 3×3 | รวมทุกการแปลงเป็นเมทริกซ์เดียวต่อหนึ่งตัวอักษร | `correction.py`, `geometry.about`, `blend` |
| Moving average (circulant matrix) | ทำเส้นเรียบ (โหมด contour), ทำการบิดเฉพาะจุดให้เรียบ | `geometry.circulant_ma_matrix`, `moving_average_closed` |

## ตัวชี้วัด (ยิ่งต่ำยิ่งเป็นระเบียบ ยกเว้นความคงเอกลักษณ์)

| ตัวชี้วัด | ความหมาย |
|---|---|
| `baseline_sigma` | ส่วนเบี่ยงเบนจากเส้นบรรทัด (σ ของ residual / x-height) |
| `slant_std_deg` | ความแปรปรวนของมุมเอียงรายตัว (องศา) |
| `height_cv` | CV ของความสูงภายในกลุ่มเดียวกัน |
| `gap_cv` | CV ของช่องในคำ |
| `shape_dev` | ความต่างของรูปทรงตัวเดียวกันจากรูปเฉลี่ยของกลุ่ม |
| `line_pitch_cv` | CV ของระยะห่างระหว่างบรรทัด |
| `indent_dev` | SD ของจุดเริ่มบรรทัดในย่อหน้าระดับเดียวกัน / x-height |
| `identity_cos` | cosine similarity ของรูปทรงก่อน/หลัง (1 = เหมือนเดิม) |
| OCR confidence | ค่าความมั่นใจเฉลี่ยของ tesseract ก่อน/หลัง (ไม่บังคับ) |

บรรทัดหรือตัวอักษรที่ระบบคงไว้ (freeze) ไม่นับในตัวชี้วัด

## พารามิเตอร์ที่ควรลองจูนก่อน

| พารามิเตอร์ | ผล |
|---|---|
| `alpha` | ความแรงรวม: ยิ่งสูงยิ่งเป็นระเบียบ แต่เปลี่ยนรูปมากขึ้น |
| `slant_target` | `page_median` คงความเอียงประจำตัวผู้เขียน, `vertical` ตั้งตรง |
| `slant_shrink_n0` | ยิ่งน้อยยิ่งแก้เอียงรายตัวแรง |
| `shape_strength` / `shape_nonrigid` | แรงดึงรูปทรงเข้าหาต้นแบบ (affine / บิดเฉพาะจุด) |
| `shape_cos_min` | ต่ำ = จับกลุ่มได้มากขึ้น แต่เสี่ยงจับตัวที่แค่คล้ายกันไว้ด้วยกัน |
| `regularize_spacing` / `regularize_indent` | เปิด/ปิดการจัดระยะบรรทัดและแนวหน้าบรรทัด |
| `thresh_C` | ภาพจางหรือหมึกหาย → ลด, มี noise เยอะ → เพิ่ม |
| `mark_height_h` | สระ/วรรณยุกต์ถูกนับเป็นตัวฐาน → เพิ่ม, ตัวเล็กถูกนับเป็นสระ → ลด |
| `output_bg` | `paper` วางบนกระดาษเดิม, `white` พื้นขาว |
| `render_mode` | `warp` คงเส้นเดิม, `contour` เส้นเรียบ |

## สคริปต์ประกอบรายงาน

```bash
python report_tools/make_figures.py notes.pdf --page 2 --out figures        # ภาพไล่ pipeline ทีละขั้น (fig01–fig20) + numbers.json
python report_tools/dataset_stats.py data/ --out dataset_out                # สถิติชุดข้อมูล + การคัดกรอง → summary.md / summary.json / กราฟ
python report_tools/identity_vs_ocr.py notes.pdf --pages all --out report_out   # เทียบ ต้นฉบับ / Rewrite Reborn / OCR
```

`dataset_stats.py` นับข้อมูล 1 ชุด = 1 หน้า และจัดแต่ละหน้าเป็น สมบูรณ์ / ต้องแก้ไข / ตัดทิ้ง
เกณฑ์ปรับได้ที่ค่าคงที่ส่วนต้นของไฟล์ (`MIN_H`, `LOWRES_H`, `MIN_GLYPHS`, `FROZEN_MAX`, `SKEW_FIX`, `LIGHT_CV`)

- **เป็นระเบียบขึ้นไหม:** ตัวชี้วัดชุดเดียวกับข้างบน รวมเป็นดัชนี = ค่าเฉลี่ยของ % ที่ดีขึ้นจากต้นฉบับ
- **ยังคงเอกลักษณ์ไหม:** cosine similarity ของภาพระดับคำเทียบกับต้นฉบับ (ทุกแบบถูกยืดให้เท่ากรอบเดิมและ blur σ = 2 px ก่อนวัด) พร้อมไม้บรรทัดคือ "ผู้เขียนเขียนคำเดิมซ้ำ" (cos ระหว่างคำเดียวกันสองครั้งในต้นฉบับ) และผลทดสอบความไวต่อ σ

## ข้อจำกัดที่รู้แล้ว

- **ตัวอักษรที่เขียนติดกัน:** ถูกปรับเป็นหน่วยเดียว ยังแยกตัวไม่ได้
- **สูตรลายมือ:** เศษส่วนและสูตรที่ซ้อนหลายชั้นถูกคงไว้ตามเดิม ตัวยก/ตัวห้อยจัดการได้บางส่วน เส้นเศษส่วนที่ตัวเศษเขียนแตะอาจไม่ถูกจับเป็นเศษส่วน
- **ภาพความละเอียดต่ำ:** ถ้าตัวอักษรสูงต่ำกว่าประมาณ 10 px ผลจะแย่ลง ควรใช้ภาพหรือ PDF ที่ละเอียดกว่า
- **ช่องไฟก้ำกึ่ง:** ช่องที่แยกไม่ออกว่าเป็นช่องในคำหรือระหว่างคำจะคงไว้ตามเดิม
- **รูปทรงสม่ำเสมอ:** ครอบคลุมราว 15–25% ของตัวในหน้า เพราะต้องมีตัวที่หน้าตาเหมือนกันอย่างน้อย 3 ตัว และตัวชี้วัด `shape_dev` วัดในกลุ่มเดียวกับที่ใช้ปรับ
- **ไฮไลต์:** คงไว้ที่ตำแหน่งเดิม ไม่เลื่อนตามคำ
- **PDF แบบ vector:** ถูกแปลงเป็นภาพคมชัดก่อนประมวลผล ยังไม่ได้ดึงเส้นปากกาจาก path โดยตรง
- **การผูก ำ:** นิคหิตผูกกับตัวที่อยู่ใต้มัน ถ้าเขียนเยื้องไปทาง า มากอาจผูกผิดตัว
