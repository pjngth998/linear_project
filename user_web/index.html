ระบบทำงานอย่างไร

  1. แยกตัวอักษร ระบบหาขอบของหมึกแต่ละชิ้น แล้วเก็บเป็นชุดจุดพิกัด สระและวรรณยุกต์ถูกผูกกับพยัญชนะของมัน
  2. หาเส้นบรรทัด ลากเส้นที่ใกล้จุดล่างของตัวอักษรในบรรทัดมากที่สุด
  3. คำนวณการปรับ แต่ละตัวได้เมทริกซ์ 1 ตัวที่รวมการแก้เอียง ปรับขนาด และเลื่อนลงเส้นบรรทัด
  4. ยกหมึกจริงไปวาง ไม่ได้วาดใหม่หรือเปลี่ยนเป็นตัวพิมพ์ ความหนาและสีของเส้นจึงเหมือนเดิม
